# Contributing to RETECO

Thank you for helping improve the RETECO task resources.

## Documentation and website changes

1. Create a focused branch.
2. Preview `docs/` locally with `python -m http.server 8000 --directory docs`.
3. Check desktop and mobile layouts.
4. Verify that every factual task change agrees with the accepted proposal or
   a later official organizer decision.
5. Open a pull request describing the participant-facing effect.

## Content rules

- Never commit hidden-test gold labels, private annotation material,
  credentials, API keys, or participant submissions.
- Mark unconfirmed dates and links as tentative or coming soon.
- Use the central SemEval calendar as the authority for shared deadlines.
- Preserve data provenance, attribution, and licenses.
- Keep task definitions, evaluation documentation, and format examples in sync.

## Reporting data issues

During evaluation, potentially exploitable data issues should be reported
privately to the organizers rather than in a public issue.
